# Diário de Bordo - Desenvolvedor de Sistemas

## 📚 Conteúdo da Primeira Aula

Seja bem-vindo ao repositório de registro das aulas do curso de **Desenvolvimento de Sistemas** (*System Development*). Este espaço será utilizado para armazenar e organizar todas as aplicações, códigos e notas desenvolvidos ao longo da nossa jornada acadêmica.

---

### 🎲 Atividades e Dinâmicas Iniciais
* **Dinâmica do Cubo-Box:** Realizamos uma atividade de integração para que a turma pudesse se conhecer e quebrar o gelo no primeiro contato com o ambiente de aprendizado.

### 🗺️ Visão Geral do Curso
Foi apresentada a estrutura curricular do curso através de uma apresentação de slides. O curso é composto por **4 Unidades Curriculares (UCs)** essenciais para a formação profissional em desenvolvimento de software.

### ⚙️ Ferramentas Utilizadas & Configurações de Ambiente

#### 🐱 GitHub
* Criação e configuração de conta pessoal na plataforma.
* Introdução aos conceitos de versionamento de código.
* Criação deste repositório para guardar e organizar todas as aplicações práticas das aulas.

#### 💻 Visual Studio Code (VS Code)
* Instalação e primeiros passos com a IDE.
* Aprendizado prático sobre comandos, atalhos e boas práticas de codificação.

#### 📁 Organização de Arquivos
* Configuração e salvamento dos arquivos das aulas em uma pasta privada do sistema local, garantindo a integridade dos códigos desenvolvidos.

---

### 🚀 Como utilizar este repositório
1. Clone o repositório para a sua máquina local.
2. Abra a pasta do projeto no seu **VS Code**.
3. Navegue pelas pastas correspondentes a cada aula ou UC para revisar o conteúdo.
